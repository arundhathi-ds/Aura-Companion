# UI Behavior Rules

- Maintain dark cinematic atmosphere
- Preserve glassmorphism cards and floating UI
- Preserve motion and particle effects
- Maintain soft gradients and blur effects
- Preserve typography and spacing system
- Keep smooth transitions and emotional visual tone
- Never modernize or simplify the interface
- **Cinematic Time Engine**: The UI must subtly change based on local time and emotional weather. Use CSS variables to dynamically control ambient glow color, blur intensity, and animation speed.
- Late-night usage should feel dimmer, slower, and more reflective.
- Morning usage should feel soft and warmly lit.
